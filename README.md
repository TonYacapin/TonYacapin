### Features

| Category | Features |
|---|---|
| Sales | Checkout, transaction history, sales reports |
| Inventory | Products, stock monitoring, barcode scanning |
| Finance | Puhunan, profit, expenses |
| Customers | Utang ledger and payment tracking |
| Management | Restock list, backup and restore |

**Free Business Tools**

Barcode Generator · Sell Price Calculator · Recipe Coster · Per-Kilo Calculator · SRP Maker · Store Signs · Catalog Setup

**Built with** React Native · Expo · TypeScript
