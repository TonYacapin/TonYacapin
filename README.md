### Features

- Sales and checkout
- Inventory and stock management
- Barcode scanning
- Customer utang ledger
- Sales history and analytics
- Puhunan and profit tracking
- Restock list
- Backup, import and export

**Free web tools:** Barcode Generator, Sell Price Calculator, Recipe Coster, Per-Kilo Calculator, SRP Maker, Store Signs, and Catalog Setup.

**Tech:** React Native, Expo, TypeScript
